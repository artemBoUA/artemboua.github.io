# artemboua.github.io

Root of the GitHub Pages host. It serves the files that must live at the root of the domain:

- `.well-known/apple-app-site-association` (iOS Universal Links of the DoIt app)
- `.well-known/assetlinks.json` (Android App Links of the DoIt app)

The DoIt website itself (support, privacy policy, smart links) is in https://github.com/artemBoUA/doit and is served under `/doit/`.
